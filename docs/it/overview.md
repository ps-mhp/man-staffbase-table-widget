# Tabella

Il widget Tabella inserisce in una pagina una tabella dotata di un proprio editor di griglia
. A differenza di una semplice tabella di testo, è possibile formattare le celle
(grassetto, corsivo, colori, allineamento…), unire, riempire con immagini e
ordinare — direttamente nella finestra di dialogo di configurazione, senza alcuna conoscenza di HTML o
di tabelle.

Il widget è adatto a tutto ciò che deve essere rappresentato in forma tabellare:
tabelle comparative, elenchi di contatti, indicatori chiave, orari o
prospetti dei prezzi. Tramite il pulsante di importazione è possibile importare un file `.csv`
o `.xlsx`/`.xls` esistente, invece di creare la tabella manualmente.

Per impostazione predefinita, le tabelle molto lunghe mostrano sulla pagina pubblicata solo
le prime righe e possono essere espanse tramite un pulsante «Mostra tutto»
— in questo modo la tabella rimane chiara e ordinata, senza che i contenuti
vengano persi.
