# Impostazioni

Nella finestra di dialogo di configurazione è presente, tecnicamente, un solo campo: **Dati tabella**.
In esso è contenuta la tabella nella forma salvata; la modifica avviene
esclusivamente tramite l’**Editor tabella**, che si apre automaticamente
sopra di essa. Una volta chiuso l’editor, il pulsante **Modifica tabella**
lo riapre.

## Barra di intestazione dell’editor

La barra di intestazione è uguale in tutti i widget MAN.

| Pulsante | Funzione |
| --- | --- |
| Chiudi (a sinistra) | Esce dall’editor. Se sono presenti modifiche non salvate, chiede: Ignora, Continua a modificare o Salva. |
| Stato nel titolo | «Nessuna modifica» o ciò che è in sospeso, ad esempio «3 celle modificate – non salvate», «Struttura modificata», «Impostazioni modificate». |
| Editor · Desktop · Tablet · Mobile | Passa dalla modalità di modifica all’anteprima della tabella pubblicata in base alla larghezza del dispositivo. |
| Annulla, Ripeti | Annulla o ripristina le operazioni precedenti. |
| Aiuto | Apre a destra la guida rapida per ogni funzione e i pulsanti. |
| Annulla | Come “Chiudi”. |
| Applica | Scrive la tabella nella finestra di dialogo del widget e chiude. Il salvataggio avviene solo con “Salva” in Studio. |

## Schede della barra degli strumenti

| Scheda | Cosa contiene |
| --- | --- |
| Carattere | Dimensione carattere (predefinita, 10–32), ingrandisci/riduci carattere, grassetto, corsivo, sottolineato, barrato, apice, pedice, colore carattere, colore sfondo. |
| Allineamento | Allineamento a sinistra, centrato, allineamento a destra, nonché in alto, al centro, in basso. |
| Celle | Unire, separare, inserire (riga sopra/sotto, colonna a sinistra/a destra), eliminare (riga/e, colonna/e). |
| Immagini | Inserisci immagine nella cella, Adegua dimensioni immagine (stessa altezza/larghezza della prima immagine, dimensione predefinita). |
| Dati | Copia formato, Rimuovi formattazione. |

A destra delle schede si trova **Importa (.csv, .xlsx)**: legge un
file e sostituisce l’intera tabella.

## Pannello «Tabella»

A destra della tabella si trovano le impostazioni che si applicano all’intera tabella
. Rimane visibile anche nell’anteprima.

| Impostazione | Descrizione |
| --- | --- |
| Primo ordinamento | *Nessuno* (impostazione predefinita) oppure una colonna, con *Crescente* o *Decrescente*. In questo modo la tabella viene ordinata all’apertura; la riga di intestazione rimane in alto. I lettori possono riordinare cliccando su un’intestazione. È possibile impostare l’ordinamento anche tramite il menu contestuale → Ordinamento. |
| Righe visibili | Numero di righe di dati immediatamente visibili sulla pagina; il resto è nascosto dietro un pulsante di visualizzazione. Impostazione predefinita 5, `0` significa «sempre tutte le righe». La riga di intestazione non viene conteggiata. |
| Esportazione | *Disattivata* (impostazione predefinita), *Tutta la tabella* o *Con selezione delle righe*. Sopra la tabella compaiono quindi i pulsanti «Excel (.xlsx)» e «CSV»; con la selezione delle righe, a sinistra viene aggiunta una colonna con caselle di selezione; vengono esportate le righe selezionate (senza selezione, tutte). Nell’app Staffbase (iOS/Android) l’opzione di esportazione non viene visualizzata. |
| Adatta immagini | Se attivata, tutte le immagini rimangono entro la larghezza della tabella. Se disattivata, ogni immagine appare nelle sue dimensioni originali — e può superare i limiti della tabella. |

Nella parte inferiore del pannello è indicata la versione del widget.
