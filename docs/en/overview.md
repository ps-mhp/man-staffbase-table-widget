# Table

The Table widget embeds a table with its own grid editor into a page
. Unlike a simple text table, you can format cells
(bold, italic, colors, alignment, etc.), merged, filled with images, and
sorted—directly in the configuration dialog, without any knowledge of HTML or
spreadsheets.

The widget is suitable for anything that needs to be presented in tabular form:
comparison tables, contact lists, key metrics, class schedules, or
price lists. The Import button allows you to import an existing `.csv`
or `.xlsx`/.`xls` file instead of building the table manually.

By default, very long tables display only
the first few rows on the published page and can be expanded using a “Show All” button
— this keeps the table organized without
losing any content.
