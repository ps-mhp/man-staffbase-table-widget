# Settings

Technically, there is only one field in the configuration dialog—**Table Data**.
This field contains the table in its saved form; it is edited
exclusively using the **Table Editor**, which opens automatically
above it. Once the editor is closed, the **Edit Table**
button brings it back.

## Editor Header Bar

The header bar is the same in all MAN widgets.

| Button | Effect |
| --- | --- |
| Close (left) | Exits the editor. If there are unsaved changes, it asks: Discard, Continue editing, or Apply. |
| Status in the title bar | “No changes” or whatever is pending, such as “3 cells changed – not applied,” “Structure changed,” “Settings changed.” |
| Editor · Desktop · Tablet · Mobile | Switches between editing mode and the preview of the published table in device-specific width. |
| Undo, Redo | Undoes or redoes steps. |
| Help | Opens a quick help guide on the right for each function and the buttons. |
| Cancel | Same as Close. |
| Apply | Writes the table to the widget dialog and closes it. Changes are not saved until you click “Save” in Studio. |

## Toolbar Tabs

| Tab | What it contains |
| --- | --- |
| Font | Font size (default, 10–32), increase/decrease font size, bold, italic, underline, strikethrough, superscript, subscript, font color, background color. |
| Alignment | Left-aligned, Centered, Right-aligned, as well as Top, Middle, Bottom. |
| Cells | Merge, Unmerge, Insert (row above/below, column left/right), Delete (row(s), column(s)). |
| Images | Insert image into cell, adjust image size (same height/width as first image, default size). |
| Data | Copy format, remove formatting. |

To the right of the tabs is **Import (.csv, .xlsx)**: imports a
file and replaces the entire table.

## “Table” Panel

To the right of the table are the settings that apply to the entire table
. It remains visible in the preview as well.

| Setting | Description |
| --- | --- |
| Initial Sort | *None* (default) or a column, plus *Ascending* or *Descending*. This is how the table is sorted when opened; the header row remains at the top. Readers can reorder the table by clicking on a header. You can also set the sort order via the context menu → Sort. |
| Visible Rows | Number of data rows immediately visible on the page; the rest are hidden behind a “Show” button. Default is 5; `0` means “always show all rows.” The header row is not included in this count. |
| Export | *Off* (default), *Entire Table*, or *With Row Selection*. The “Excel (.xlsx)” and “CSV” buttons then appear above the table; with “Selected Rows,” a column of checkboxes appears on the left, and only the selected rows are exported (all rows are exported if nothing is selected). The export option is not displayed in the Staffbase app (iOS/Android). |
| Adjust Images | When enabled, all images fit within the table width. When disabled, each image appears in its original size—and may cause the table to overflow. |

The widget version is displayed at the bottom of the panel.

## Additional Tools

| Tool | Description |
| --- | --- |
| Copy Format (Data tab) | Applies the format of the currently selected cell to the next selected cells. |
