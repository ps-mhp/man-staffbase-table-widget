# Schritt für Schritt

## Erste Tabelle anlegen

1. Das Widget **Tabelle** auf der Seite platzieren und die Widget-Einstellungen
   öffnen. Der **Tabellen-Editor** erscheint automatisch über dem Feld
   „Tabellendaten“.
2. In eine Zelle **doppelklicken** und den Text eintippen. Mit einem Klick auf
   eine andere Zelle wird die Eingabe übernommen.
3. Die **erste Zeile** mit den Spaltenüberschriften füllen.
4. Fehlen Zeilen oder Spalten: Reiter **Zellen** → **Einfügen** → z. B. „Zeile
   unterhalb“ oder „Spalte rechts“.
5. Oben rechts auf **Speichern** klicken. Erst dadurch landet die Tabelle im
   Widget.
6. Mit **Schließen** den Editor verlassen und die Seite speichern.

Steht neben den Buttons **„Ungespeicherte Änderungen“**, wurde noch nicht
gespeichert — dann erst „Speichern“ klicken, dann „Schließen“.

## Bestehende Tabelle aus Excel oder CSV übernehmen

1. Im Tabellen-Editor den Reiter **Daten** öffnen.
2. Auf **Importieren** klicken und die Datei wählen (`.csv`, `.xlsx` oder
   `.xls`).
3. Das Ergebnis prüfen: Der Import **ersetzt die komplette Tabelle**, es wird
   nichts angehängt. Aus Excel bleiben verbundene Zellen, Fett/Kursiv/
   Unterstrichen, Farben, Schriftgrößen, Ausrichtung sowie Hoch- und
   Tiefstellungen erhalten. Bei einer Excel-Mappe wird das **erste
   Tabellenblatt** verwendet.
4. **Speichern**.

Alternativ lassen sich Zellen auch direkt aus Excel **kopieren und einfügen**:
in eine Zelle doppelklicken und einfügen — der Block wird ab dieser Stelle
über mehrere Zellen verteilt.

## Zellen formatieren

1. Die zu formatierenden Zellen markieren: klicken, mit gedrückter Maustaste
   ziehen, mit **Umschalt** einen Bereich aufziehen oder mit **Strg/Cmd**
   weitere Bereiche dazunehmen. Über die Griffe am Rand lassen sich ganze
   Zeilen, Spalten oder die ganze Tabelle markieren.
2. Reiter **Schrift** für Schriftgröße, Fett, Kursiv, Unterstrichen,
   Durchgestrichen, Hoch-/Tiefstellen, Schrift- und Hintergrundfarbe.
3. Reiter **Ausrichtung** für links/zentriert/rechts und oben/mittig/unten.
4. **Speichern**.

Um eine Formatierung auf weitere Zellen zu übertragen:

1. Eine bereits formatierte Zelle markieren.
2. Reiter **Daten** → **Format** anklicken.
3. Die Zielzellen markieren — sie übernehmen das Format.

## Zellen verbinden

1. Die zu verbindenden Zellen markieren.
2. Reiter **Zellen** → **Verbinden**.
3. Rückgängig machen mit **Lösen**.

## Bild in eine Zelle einfügen

1. Die Zelle markieren.
2. Reiter **Bilder** → **Bild**. Die Medienauswahl öffnet sich; dort ein
   vorhandenes Bild wählen oder ein neues hochladen.
3. Sind mehrere Bilder unterschiedlich groß: alle Bildzellen markieren und
   über **Bildgröße** entweder „Gleiche Höhe wie erstes Bild“ oder „Gleiche
   Breite wie erstes Bild“ wählen (dafür braucht es mindestens zwei Bilder).
   **Standardgröße** setzt zurück.
4. Sprengt ein Bild die Tabelle, im Reiter **Bilder** den Schalter **Bilder
   anpassen** einschalten — dann bleiben alle Bilder innerhalb der
   Tabellenbreite.

## Tabelle sortieren

1. Die Spalte markieren, nach der sortiert werden soll.
2. Reiter **Daten** → **Sortieren** → „Aufsteigend (diese Spalte)“ oder
   „Absteigend (diese Spalte)“.
3. **Speichern**. Diese Sortierung ist die Startsortierung für alle
   Leser:innen; die Kopfzeile bleibt dabei immer oben.

## Lange Tabelle einklappen

1. Reiter **Daten** öffnen.
2. Unter **Sichtbare Zeilen** die Anzahl der Datenzeilen eintragen, die sofort
   zu sehen sein sollen. Voreingestellt sind 5; `0` zeigt immer alle Zeilen.
3. **Speichern**. Auf der Seite erscheint dann unter der Tabelle ein Button
   „Weitere N Zeilen einblenden“ bzw. „Weniger Zeilen anzeigen“.

## Formatierung wieder entfernen

1. Die betroffenen Zellen markieren.
2. Reiter **Daten** → **Formatierung** und den passenden Eintrag wählen:
   alles entfernen, nur die Textformatierung oder nur die Bildgrößen.
3. **Speichern**.
