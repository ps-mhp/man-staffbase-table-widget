# Einstellungen

Im Konfigurationsdialog gibt es technisch nur ein Feld — **Tabellendaten**.
Darin steht die Tabelle in gespeicherter Form; bearbeitet wird sie
ausschließlich über den **Tabellen-Editor**, der sich automatisch darüber
öffnet. Ist der Editor einmal geschlossen, bringt ihn der Button **Tabelle
bearbeiten** zurück.

## Kopfleiste des Editors

Die Kopfleiste ist in allen MAN-Widgets gleich.

| Schaltfläche | Wirkung |
| --- | --- |
| Schließen (links) | Verlässt den Editor. Mit offenen Änderungen fragt er nach: Verwerfen, Weiter bearbeiten oder Übernehmen. |
| Status am Titel | „Keine Änderungen“ oder was offen ist, etwa „3 Zellen geändert – nicht übernommen“, „Struktur geändert“, „Einstellungen geändert“. |
| Editor · Desktop · Tablet · Mobil | Wechselt zwischen Bearbeiten und der Vorschau der veröffentlichten Tabelle in Gerätebreite. |
| Rückgängig, Wiederholen | Nimmt Schritte zurück bzw. stellt sie wieder her. |
| Hilfe | Öffnet rechts die Kurzhilfe zu jeder Funktion und die Tasten. |
| Abbrechen | Wie Schließen. |
| Übernehmen | Schreibt die Tabelle in den Widget-Dialog und schließt. Gesichert wird erst mit „Speichern“ im Studio. |

## Reiter der Werkzeugleiste

| Reiter | Was darin steckt |
| --- | --- |
| Schrift | Schriftgröße (Standard, 10–32), Schrift vergrößern/verkleinern, Fett, Kursiv, Unterstrichen, Durchgestrichen, Hochstellen, Tiefstellen, Schriftfarbe, Hintergrundfarbe. |
| Ausrichtung | Linksbündig, Zentriert, Rechtsbündig sowie Oben, Mittig, Unten. |
| Zellen | Verbinden, Lösen, Einfügen (Zeile oberhalb/unterhalb, Spalte links/rechts), Löschen (Zeile(n), Spalte(n)). |
| Bilder | Bild in Zelle einfügen, Bildgrößen angleichen (gleiche Höhe/Breite wie erstes Bild, Standardgröße). |
| Daten | Format kopieren, Formatierung entfernen. |

Rechts neben den Reitern steht **Importieren (.csv, .xlsx)**: liest eine
Datei ein und ersetzt die ganze Tabelle.

## Panel „Tabelle“

Rechts neben der Tabelle stehen die Einstellungen, die für die ganze Tabelle
gelten. Es bleibt auch in der Vorschau sichtbar.

| Einstellung | Beschreibung |
| --- | --- |
| Erste Sortierung | *Keine* (Voreinstellung) oder eine Spalte, dazu *Aufsteigend* oder *Absteigend*. So ist die Tabelle beim Öffnen sortiert; die Kopfzeile bleibt oben. Leser:innen sortieren per Klick auf eine Überschrift um. Auch über das Kontextmenü → Sortierung zu setzen. |
| Sichtbare Zeilen | Anzahl der Datenzeilen, die auf der Seite sofort zu sehen sind; der Rest liegt hinter einem Einblenden-Button. Voreinstellung 5, `0` bedeutet „immer alle Zeilen“. Die Kopfzeile zählt nicht mit. |
| Export | *Aus* (Voreinstellung), *Ganze Tabelle* oder *Mit Zeilenauswahl*. Über der Tabelle erscheinen dann die Buttons „Excel (.xlsx)“ und „CSV“; mit Zeilenauswahl kommt links eine Spalte mit Kästchen hinzu, exportiert werden die gewählten Zeilen (ohne Auswahl alle). In der Staffbase-App (iOS/Android) wird der Export nicht angezeigt. |
| Bilder anpassen | Eingeschaltet bleiben alle Bilder innerhalb der Tabellenbreite. Ausgeschaltet erscheint jedes Bild in seiner Originalgröße — und kann die Tabelle sprengen. |

Unten im Panel steht die Version des Widgets.
