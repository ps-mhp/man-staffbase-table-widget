# Einstellungen

Das Widget hat im Konfigurationsdialog technisch nur ein Feld
(„Tabellendaten“), das den kompletten Tabelleninhalt speichert. Bearbeitet
wird es aber nie direkt als Text, sondern über den Tabellen-Editor, der sich
automatisch über diesem Feld öffnet. Die eigentlichen Einstellungen stecken
in dessen Werkzeugleiste:

| Reiter | Was er tut |
| --- | --- |
| Schrift | Schriftgröße, Fett/Kursiv/Unterstrichen/Durchgestrichen, Hoch-/Tiefstellen, Text- und Hintergrundfarbe sowie „Versalien aufheben“ (hebt automatische Großschreibung der Seite für die Markierung wieder auf). |
| Ausrichtung | Horizontale (links/zentriert/rechts) und vertikale (oben/mittig/unten) Ausrichtung des Zellinhalts. |
| Zellen | Zellen verbinden/lösen, Zeilen und Spalten einfügen oder löschen. |
| Bilder | Bild in die markierte Zelle einfügen, Bildgrößen mehrerer markierter Bilder angleichen oder zurücksetzen. |
| Daten | Sortieren nach Spalte, Format-Pinsel, Anzahl sichtbarer Zeilen, Formatierung entfernen, Tabelle aus `.csv`/`.xlsx`/`.xls` importieren. |

Zusätzliche Einstellung außerhalb der Werkzeugleiste:

| Einstellung | Beschreibung |
| --- | --- |
| Sichtbare Zeilen | Legt fest, wie viele Datenzeilen auf der veröffentlichten Seite gezeigt werden, bevor sich die Tabelle hinter einem „Alle anzeigen“-Button einklappt. `0` zeigt immer alle Zeilen. Einstellbar über den Reiter „Daten“. |

„Speichern“ übergibt den aktuellen Stand an das Widget, „Schließen“ verwirft
nichts von sich aus, verlässt den Dialog aber ohne zu speichern —
ungespeicherte Änderungen zeigt ein Hinweis neben den beiden Buttons an. Ein
eigener Hilfe-Reiter im Editor erklärt jede Funktion noch einmal im Detail.
