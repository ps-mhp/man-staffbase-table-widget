# Tabla

El widget de tabla incrusta una tabla con su propio editor de cuadrícula en una página
. A diferencia de una tabla de texto sencilla, permite dar formato a las celdas
(negrita, cursiva, colores, alineación…), se pueden unir, rellenar con imágenes y
ordenar, directamente en el cuadro de diálogo de configuración, sin necesidad de tener conocimientos de HTML o
de hojas de cálculo.

El widget es ideal para todo lo que se quiera presentar en forma de tabla:
tablas comparativas, listas de personas de contacto, indicadores clave, horarios o
listas de precios. Mediante el botón de importación se puede importar un archivo `.csv`
o `.xlsx`/`.xls` ya existente, en lugar de crear la tabla a mano.

Por defecto, las tablas muy largas solo muestran
las primeras filas en la página publicada y se pueden desplegar mediante un botón «Mostrar todo»
; de este modo, la tabla se mantiene clara sin que se
pierda contenido.
